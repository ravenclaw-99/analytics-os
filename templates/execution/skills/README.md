# Skills

One folder per recurring task, each holding a `SKILL.md` in the Agent Skills format (`name` and `description`, then the steps). Skills **link** to definitions with `[[id]]` and never restate them.

To add one, copy [`blanks/skill/SKILL.md`](../../blanks/skill/SKILL.md) here, fill in the frontmatter, and run the checker.

Copy the folder to `execution/skills/<skill-name>/`.
